## 연습 문제 1: 벡터의 결합과 크기 확인

**문제:** 1부터 5까지의 값을 갖는 벡터 `A`와 그 복사본 `B`를 만들고, 길이를 확인한 뒤 열 방향과 행 방향으로 결합하고, 열 방향으로 결합한 결과 `C`의 행과 열의 수를 확인하라. 단계별 지시는 [연습 문제 1](Exercises.ko.md#연습-문제-1-벡터의-결합과-크기-확인)에 있다.

### 풀이

**접근 방법:** 벡터는 `c()`로 만들고([1강 6.1절](Concepts_Lecture.ko.md#61-벡터와-할당)), 할당 연산자 `<-`로 복사한다. `cbind()`(column bind)는 벡터들을 열로 세워 나란히 붙이고, `rbind()`(row bind)는 벡터들을 행으로 눕혀 위아래로 쌓는다. 두 함수의 결과는 행렬이므로 크기는 `nrow()`, `ncol()`, `dim()`으로 확인한다([1강 7.5절](Concepts_Lecture.ko.md#75-행렬-만들기)).

**코드:**

```r
A <- c(1, 2, 3, 4, 5)   # step 1 (1:5 also works)
A
B <- A                  # step 2: copy A into B
B
length(A)               # step 3
length(B)
cbind(A, B)             # step 4: column-wise
rbind(A, B)             #         row-wise
C <- cbind(A, B)        # step 5
nrow(C)                 # step 6
ncol(C)
dim(C)
class(C)
```

**실행 결과:**

```text
[1] 1 2 3 4 5
[1] 1 2 3 4 5
[1] 5
[1] 5
     A B
[1,] 1 1
[2,] 2 2
[3,] 3 3
[4,] 4 4
[5,] 5 5
  [,1] [,2] [,3] [,4] [,5]
A    1    2    3    4    5
B    1    2    3    4    5
[1] 5
[1] 2
[1] 5 2
[1] "matrix" "array" 
```

- **1, 2단계:** `A <- c(1, 2, 3, 4, 5)`는 원소 5개의 수치형 벡터를 만든다. `1:5`로 써도 값은 같다(자료형은 정수형이 된다). `B <- A`는 `A`의 값을 `B`에 복사한다.
- **3단계:** 두 벡터 모두 원소가 5개이므로 길이는 5이다.
- **4단계:** `cbind(A, B)`는 `A`와 `B`를 각각 하나의 열로 세워 5행 2열 행렬을 만들고, 변수 이름이 열 이름(`A`, `B`)이 된다. `rbind(A, B)`는 두 벡터를 각각 하나의 행으로 쌓아 2행 5열 행렬을 만들고, 변수 이름이 행 이름이 된다. 두 결과는 서로의 전치(`t()`)이다.
- **5, 6단계:** `C`는 `cbind(A, B)`의 결과이므로 행이 5개, 열이 2개이고, `dim(C)`는 두 값을 한꺼번에 `5 2`로 돌려준다. `class(C)`가 보여 주듯 `C`는 데이터 프레임이 아니라 행렬이다.

> **참고:** R에서 `B <- A`로 복사한 뒤 `B`를 고쳐도 `A`는 바뀌지 않는다. R은 복사본을 고치는 순간 실제로 메모리를 따로 만들기 때문이다(copy-on-modify). 다음 코드에서 `B[1] <- 100`을 실행한 뒤에도 `A`는 그대로이다.
>
> ```r
> B[1] <- 100
> A
> B
> ```
>
> ```text
> [1] 1 2 3 4 5
> [1] 100   2   3   4   5
> ```

## 연습 문제 2: 성별과 키 데이터 만들기

**문제:** 처음 10개는 Male, 나머지 10개는 Female인 성별과, 남성은 $N(173, 2^2)$, 여성은 $N(162.3, 2^2)$에서 생성한 키로 이루어진 20행 2열의 표를 만들고, 행렬과 데이터 프레임 가운데 알맞은 구조를 설명하라. 조건은 [연습 문제 2](Exercises.ko.md#연습-문제-2-성별과-키-데이터-만들기)에 있다. 여기서 $N(\mu, \sigma^2)$은 평균이 $\mu$, 분산이 $\sigma^2$인 정규분포를 뜻한다.

### 풀이

**접근 방법:** 집단별 키는 `rnorm()`으로 10개씩 생성하고([1강 7.3절](Concepts_Lecture.ko.md#73-정규분포-난수-rnorm)), 성별은 `rep()`으로 같은 값을 10번씩 반복하여 만든다([1강 7.1절](Concepts_Lecture.ko.md#71-객체-삭제와-반복-rep)). 성별은 문자, 키는 숫자로 자료형이 다르므로, 두 변수를 한 표에 담으려면 **데이터 프레임**을 써야 한다([1강 6.6절](Concepts_Lecture.ko.md#66-데이터-프레임과-행렬의-차이)). 결과를 재현할 수 있도록 난수를 만들기 전에 시드를 고정한다.

**코드:**

```r
set.seed(2025)                                         # fix the seed for reproducibility
HeightMale   <- rnorm(n = 10, mean = 173,   sd = 2)    # 10 male heights
HeightFemale <- rnorm(n = 10, mean = 162.3, sd = 2)    # 10 female heights
Gender <- factor(c(rep("Male", 10), rep("Female", 10)))
Height <- c(HeightMale, HeightFemale)
ourData <- data.frame(Gender = Gender, Height = Height)
ourData
str(ourData)
```

**실행 결과:**

```text

5    Male 173.7420

 $ Height: num  174 173 175 176 174 ...
```

- **`set.seed(2025)`:** 난수 생성기의 시작점을 고정한다. 같은 시드로 같은 순서의 명령을 실행하면 위와 같은 값이 다시 나온다. 시드를 고정하지 않거나 다른 시드를 쓰면 값은 달라지지만, 남성의 키가 173 근처에, 여성의 키가 162.3 근처에 흩어진다는 성질은 같다.
- **`rnorm(n = 10, mean = 173, sd = 2)`:** 평균 173, 표준편차 2인 정규분포에서 남성의 키 10개를 만든다. 세 번째 인수는 분산이 아니라 표준편차이다. 여성의 키도 같은 방식으로 만든다.
- **`rep("Male", 10)`, `rep("Female", 10)`:** 같은 문자열을 10번씩 반복하고, `c()`로 이어 붙여 길이 20의 성별 벡터를 만든다. `factor()`로 감싸 범주형 변수(팩터)로 저장하므로, 수준은 알파벳순인 Female, Male이 된다.
- **`Height <- c(HeightMale, HeightFemale)`:** 두 집단의 키를 이어 붙인다. 앞의 10개가 남성이므로 성별 벡터의 순서와 맞는다.
- **`data.frame(Gender = Gender, Height = Height)`:** 두 벡터를 열로 하는 데이터 프레임을 만든다. `str()`의 출력에서 `Gender`는 팩터, `Height`는 수치형으로 각자의 자료형을 유지한다.

**행렬과 데이터 프레임:** 같은 표를 `cbind()`로 행렬로 만들면 문제가 생긴다. 행렬은 모든 원소가 같은 자료형이어야 하므로, 문자열인 성별 때문에 키까지 문자열로 바뀌고 평균을 계산할 수 없다.

```r
m <- cbind(Gender = c(rep("Male", 10), rep("Female", 10)),
           Height = c(HeightMale, HeightFemale))
head(m, 3)
mean(m[, "Height"])
```

```text
     Gender Height            
[1,] "Male" "174.241513471773"
[2,] "Male" "173.071282807422"
[3,] "Male" "174.546308968686"
[1] NA
Warning message:
In mean.default(m[, "Height"]) :
  argument is not numeric or logical: returning NA
```

성별을 팩터로 넣어도 행렬에서는 정수 코드(Female은 1, Male은 2)로 바뀌어 범주 정보가 사라진다. 따라서 서로 다른 자료형의 변수를 함께 담는 이 표는 **데이터 프레임**으로 만들어야 한다. 표의 출력 예가 행 번호와 열 이름을 갖고 문자열에 따옴표가 없는 것도 데이터 프레임의 출력 형식이다.

> **참고:** 문제에 제시된 출력 예와 위 실행 결과의 키 값이 다른 것은 난수의 시드가 다르기 때문이다. 두 결과 모두 남성의 키는 170 ~ 179 부근, 여성의 키는 158 ~ 168 부근에 있어 조건을 만족한다.

이 데이터로 집단별 기술 통계를 구하고 분포를 그리는 방법은 [1강 8절](Concepts_Lecture.ko.md#8-기술-통계와-시각화)에 있다.
