## 연습 문제 1: 두 주사위의 세 사건

- 사건 $A$: 두 눈의 합이 짝수이다.
- 사건 $B$: 두 눈의 합이 8 이상이다.
- 사건 $C$: 두 눈의 차이가 1 이하이다.

이어서 $A \cap B$, $A \cap C$, $B \cap C$, $A \cap B \cap C$, $B^c$, $A \cap B^c$의 원소를 구하라.

## 연습 문제 7: 다섯 주사위와 독립성

**문제:** 주사위 다섯 개를 던질 때 다음 두 사건이 서로 독립인지 R로 판정하라.

- 사건 $A$: 다섯 눈의 합이 짝수이다.
- 사건 $B$: 나온 눈 가운데 1과 6이 모두 있다.

다음 보조 함수를 써도 된다. `pprt2()`는 사건 `x`의 확률을, `cprt2()`는 사건 `b`가 주어졌을 때 사건 `a`의 조건부 확률을 분수와 소수로 출력한다. 두 함수의 인수 `a`, `b`, `x`는 사건에 속한 결과들을 행으로 갖는 데이터 프레임이고, `an`, `bn`, `xn`은 출력에 쓸 사건의 이름이며, `n`은 표본공간의 결과의 수이다. `cprt2()`는 두 데이터 프레임에 공통으로 있는 행을 돌려주는 함수 `intersect2()`를 쓴다.

```r
cprt2 <- function(a, an, b, bn) {
  ab = intersect2(a, b)
  cat(paste0("P(", an, "|", bn, ") ="), nrow(ab), "/", nrow(b),
      "=", nrow(ab) / nrow(b))
}
pprt2 <- function(x, xn, n, prt = TRUE) {
  if (prt == TRUE) cat(paste0("P(", xn, ") ="), nrow(x), "/", n,
                       "=", nrow(x) / n, "\n")
  invisible(nrow(x) / n)
}
```
