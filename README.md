## 📝 About This Repository

- `Lecture-Notes/` holds lecture notes that follow the order of the lecture slides (`Lec##`), with exercises and solutions for each unit.
- `Coursework/` holds the assignment solutions and explanations and the lab code, with the assignment data in each item's `data/`.
- Every lecture note comes as an English (`.md`) and Korean (`.ko.md`) pair.
- The R code files carry **Doxygen-style headers**.

> **🤖 AI Agent Usage**
> [Claude Code](https://claude.ai/download) was used to organize and translate the notes and to restructure the repository.

|:----------:|:------------------|:-------------:|:---------------:|:----------------------------------------|
|`DCCS221-00`|PROBABILITY AND STATISTICS|Major Required|Prof. Minseok&nbsp;Seo|Department of Computer Science and Software Engineering|

### Course Overview

An introduction to the foundations of probability and statistics for computer science students, from probability theory through random variables and probability distributions, estimation and hypothesis testing, to nonparametric statistics, taught in English with R programming practice on the theory. The instructor, schedule, assessment, course policies, and progress are in the [course information document](Course-Information.md).
